This is a sample project to show how a project and its detail page look. Replace it with a project of your own, or remove it when you're ready.

## Tell the story

A project doesn't need to be large to deserve a page. Start with what you wanted to make, explain a few decisions, and share what you learned.

You can add images, links, code snippets, or a list of the tools you used. A short description is often enough.
